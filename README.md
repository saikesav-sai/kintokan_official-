# Kintokan 📚 (Personalized Education Guidance Companion)

Kintokan is an Android application designed to provide comprehensive educational guidance for students, focusing on study options after 10th grade. The app offers detailed information about each course to help students make informed decisions about their future education paths.

## Features ✨

- **Comprehensive Course Information 📖**: Detailed descriptions of various study options available after 10th grade.
- **Personalized Recommendations 🎯**: Tailored educational guidance based on the student's interests and academic performance.
- **User-Friendly Interface 🌟**: Easy-to-navigate interface designed for a smooth user experience.
